# analytics-utils

analytics-utils wraps Orkid's Keen.io telemetry patterns: typed event collectors, UTM parameter extraction, and is_bot flagging so AI-crawler traffic doesn't pollute product metrics.

## When to use

Instrumenting a TypeScript web app with Keen.io or building UTM-aware attribution.

## Install

```
npm install @orkid-labs/analytics-utils
```
